Aprende a usar la computadora, paso a paso.

PasoAPaso te acompaña con la voz, te muestra las teclas y guarda tus consultas en una cuenta con base de datos. Aquí encuentras cómo instalarlo, cómo entrar y qué hacer si algo falla.

⊞ Windows + calculadora + Enter

🔐 Tu cuenta, tu historial y el panel privado del administrador viven en una base de datos SQLite.

Empieza en 3 pasos

Solo necesitas Windows 10 u 11 y conexión para crear tu cuenta.

1

Instala Python y los componentes

Descarga Python 3.10 o más nuevo desde python.org y marca «Add Python to PATH». Luego abre una terminal en la carpeta del proyecto:

python -m pip install -r requirements.txt
2

Abre PasoAPaso

Haz doble clic en iniciar.bat. Primero verás el logo y luego la pantalla para entrar o crear tu cuenta con tu teléfono, tu nombre y una clave de 4 números.

3

Habla o escribe

Presiona el micrófono y pide lo que necesitas. Si prefieres, cambia a Escribir. PasoAPaso lo hace contigo y te explica cada paso.

¿No quieres instalar nada? También puedes abrir el portal en tu navegador para crear tu cuenta y ver tu historial. La app de Windows es la que mueve el mouse y el teclado; un navegador no puede hacer eso por seguridad.

Tu cuenta y tu historial

La base de datos guarda lo necesario para ayudarte y para que el administrador mejore las explicaciones.

Entrar es fácil

Tu usuario es tu número de teléfono y tu clave es de 4 a 8 números. No necesitas correo ni tarjeta. Si olvidas la clave, el administrador puede generarte una nueva.

Tu historial

En la app, abre Mi historial. En el navegador, entra a http://127.0.0.1:8765/portal con tu cuenta. Ahí ves lo que pediste, cómo lo hiciste y qué respondió PasoAPaso.

Tus datos, tus reglas

Puedes cambiar tu clave o borrar tu cuenta y todas tus consultas desde el portal. Solo tú y el administrador pueden ver tus datos. Leer la política de privacidad.

El chat de voz es el predeterminado

Al abrir la app, la pestaña Hablar aparece primero. Presiona el micrófono, espera el tono y habla con naturalidad. PasoAPaso te muestra lo que entendió y te pide confirmar antes de hacer algo.

  • Reconocimiento de voz en español (necesita internet).
  • Si no hay micrófono o no instalaste los componentes, puedes usar Escribir.
  • Puedes activar «Leer los pasos en voz alta» para que la app te explique hablando.
  • Con «Manos libres», vuelve a escuchar cuando termina una demostración.

Para instalar la voz:

python -m pip install SpeechRecognition sounddevice

Si el micrófono no funciona

  1. Revisa que Windows permita usar el micrófono en Configuración → Privacidad → Micrófono.
  2. Comprueba que el micrófono esté conectado y seleccionado como entrada.
  3. Instala los componentes con el comando de la izquierda.
  4. Si el reconocimiento no conecta, revisa tu internet o escribe la orden.

Problemas comunes

Toca una pregunta para ver la solución.

Abre una terminal dentro de la carpeta de PasoAPaso y escribe python -m pip install -r requirements.txt. Solo necesitas internet esta vez para instalarlo.

Lo más probable es que Python no esté instalado o que no se marcó «Add Python to PATH». Reinstala Python marcando esa casilla. Para ver el mensaje de error, abre una terminal en la carpeta y escribe python main.py.

Revisa que el teléfono sea el mismo con el que creaste la cuenta y que la clave tenga entre 4 y 8 números. Si la olvidaste, pídele al administrador que te genere una clave nueva desde el panel privado.

Instala SpeechRecognition y sounddevice (ver la sección Voz). Revisa los permisos del micrófono en Windows y que haya conexión a internet. Mientras tanto, usa la pestaña Escribir.

Por defecto se guarda en datos/pasoapaso.db, dentro de la carpeta del proyecto. Si usas el servidor en internet, se guarda en la carpeta /app/datos del servidor. Puedes cambiar la ubicación con la variable PASOAPASO_DATOS.

Solo tú y el administrador de PasoAPaso. El panel del administrador está protegido con otra clave. Si configuras Gemini, solo se envía el texto de la orden, nunca tu nombre, teléfono o clave.

Para crear la cuenta, guardar las consultas, usar la voz y consultar a la IA, sí. Las acciones sobre la computadora ocurren en tu equipo. Si no hay conexión, la app puede usar las reglas locales y guardar lo que pase para enviarlo después.

Si configuraste Gemini, la app intenta razonar la orden y convertirla a una acción permitida. Si no hay clave o la IA no está segura, usa el diccionario local. Prueba con palabras más directas: «abre la calculadora», «crea una carpeta Tareas», «busca recetas en Google».

El clic en el primer video se hace en una posición aproximada de la pantalla. Abre pasoapaso/configuracion.py y cambia POSICION_PRIMER_VIDEO, o pon REPRODUCIR_PRIMER_RESULTADO = False para que solo muestre los resultados.

Presiona el botón Detener del panel, o lleva el mouse a la esquina superior izquierda de la pantalla. En modo Instantáneo no hay panel, así que usa la esquina.

Se borran tu cuenta y todas tus consultas de la base de datos. No se puede deshacer. Puedes hacerlo desde Mi cuenta en el portal o pedírselo al administrador.

Copia la carpeta del proyecto o descarga el ZIP, instala los componentes y entra con tu mismo teléfono y clave. Si el servidor está en internet, configura PASOAPASO_API_URL con su dirección; si no, cada computadora tendrá su propia base local.

Para el administrador

El panel privado está en http://127.0.0.1:8765/admin cuando la app está abierta, o en la dirección del servidor si lo desplegaste en internet.

  • Resumen: personas registradas, consultas, uso de IA y acciones más pedidas.
  • Usuarios: buscar, ver el historial, activar o desactivar, generar una clave nueva y borrar.
  • Consultas: filtrar por texto, estado, origen y uso de IA; ver la interpretación y lo que se ejecutó.
  • Inteligencia artificial: activar o desactivar Gemini y ver qué consultas resolvió.
  • Exportar CSV: descarga todas las consultas para analizarlas en Excel.

La clave inicial de ejemplo es admin / PasoAPaso2026. Cámbiala en Mi clave antes de mostrar el proyecto.

Seguridad

  • Las claves se guardan cifradas con PBKDF2-SHA256.
  • La sesión del administrador usa una cookie firmada y privada.
  • El registro de usuarios se puede cerrar desde el panel.
  • Nunca compartas el archivo .env ni la clave de Gemini.
  • Haz copias de seguridad de datos/pasoapaso.db.
